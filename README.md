# lawrenceokolo1.github.io

Personal portfolio of Lawrence Okolo, machine learning engineer in Vancouver, BC.

Live at **https://lawrenceokolo.com**

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The build prerenders the page to static HTML (`prerender.js`) so search engines and link previews see real content.
Pushing to `main` deploys automatically through GitHub Actions (`.github/workflows/deploy.yml`).

Project content lives in `src/content.js`.
